# 05 · 版本与兼容基线

> **目的**：把“对齐哪个 pi、跑在哪个 Unity/.NET、支持到什么程度”钉死，避免开发中漂移。
> **日期**：2026-11-06

---

## 1. 上游对齐版本

| 角色 | 版本 | 用途 |
|---|---|---|
| **pi（原版）** | `v1.5.0` / `f9a263655` | 行为真相源：协议、能力面、事件语义 |
| **pi.net** | `main` / `2d6757b`（net9.0;net10.0） | 只作 C# 语言映射参考；**不作运行时基线** |
| **UnityLlmTransport** | 独立项目，版本从 `0.x` 起 | 通讯底座 |

> pi.net 目标 net9/10，使用了 `Task.WaitAsync`、`Stopwatch.GetElapsedTime`、`System.Threading.Lock` 等；这些在 Unity 2021 + netstandard2.1 下不可用。冲突时以 pi（原版）语义为准，C# 写法参考 pi.net，但不复制其运行时假设。

## 2. 运行时基线

| 项 | 决定 | 说明 |
|---|---|---|
| 语言/框架 | **C# `netstandard2.1`** | Unity 2021.3+ 可消费；测试工程 `net10.0` |
| Unity 版本 | **2021.3.45f1（主目标）**；**6000.3.28f1（6.3 LTS）**、**6000.6.8f1（6.6 最新）** 前向验证 | 实际版本由目标游戏锁定；不要求升级 |
| 脚本运行时 | **Mono 优先**；IL2CPP 需冒烟 | IL2CPP 需 `link.xml`/`[Preserve]` 保护 handler 重写 |
| 平台 | **Windows 桌面优先** | macOS/Linux 未验证；WebGL 放 M2 |
| WebGL | **M1 不支持** | 无 HttpClient/SslStream/线程；M2 用 `.jslib` + fetch |
| HTTP/2 | **2021.3 无；6.3+ UWR 可能默认 HTTP/2** | 通过 `TransportCapabilities.Http2` 表达；不依赖版本判断 |
| 代理 | UWR 仅系统代理；显式代理走 HttpClient | 各版本均无显式 UWR proxy API（以实测为准） |

**版本钉死**：

| 版本 | changeset | 角色 |
|---|---|---|
| 2021.3.45f1 | `0da89fac8e79` | 主目标 / 游戏锁定基线 |
| 6000.3.28f1 | `8f082d2fe476` | 6.3 LTS / HTTP/2 前向验证 |
| 6000.6.8f1 | `237b6593792b` | 6.6 最新 / 最新运行时验证 |
| 取消 | `CancellationToken` → `Abort()` | 取消必须中止连接 |
| 超时 | 首字节 / 空闲两个看门狗 | 不依赖 `UnityWebRequest.timeout` |
| 测试 | 纯 .NET 单测 + mock transport | 无 Unity 依赖的 Abstractions 必须可单测 |

### 3.1 版本差异（2021.3 / 6.3 / 6.6）

| 能力 | 2021.3.45f1 | 6000.3.28f1（6.3 LTS） | 6000.6.8f1（6.6） | 归一化方式 |
|---|---|---|---|---|
| HTTP 版本 | HTTP/1.1 | UWR 可能默认 HTTP/2 | UWR 可能默认 HTTP/2 | `TransportCapabilities.Http2`；上层只读 bytes |
| 网络/TLS 栈 | 较旧 | 更新 | 更新 | 证书/代理错误归一为 `Tls`/`Proxy` |
| UWR 流式 | `DownloadHandlerScript` | 同左 | 同左 | 同一个 UWR adapter；`ReceiveData` 入队 |
| UWR timeout | 语义粗 | 可能改进 | 可能改进 | 统一 `timeout=0` + 自管首/空闲看门狗 |
| WebSocket | `ClientWebSocket` | 同左 | 同左 | `IWebSocketTransport`；能力不足报 `Unsupported` |
| IL2CPP 剥离 | 需 `link.xml` | 需验证 | 需验证 | 统一 `link.xml`/`[Preserve]` |
| C# / 运行时 | C# 9 / netstandard2.1 | 更新 | 更新 | 仍按 C# 9 / netstandard2.1 编译，不用新 API |
| 代理 | 仅系统 | 仅系统（待实测） | 仅系统（待实测） | UWR `SystemProxy`；显式代理走 HttpClient |
| HTTP/2 默认 | ❌ | ⚠️ 待实测 | ⚠️ 待实测 | 能力声明，不做版本分支 |

**规则**：版本差异只能出现在 Unity 适配层的“能力/实现”里；`UnityLlmTransport.Abstractions` 和 `PiUnityAgent.Ai` 不得出现 `UNITY_*` 宏或 `Application.unityVersion` 判断。

### 3.2 兼容矩阵

| 能力 | Unity 2021.3 Mono | IL2CPP | WebGL | .NET 8 后端 |
|---|---|---|---|---|
| UWR + DownloadHandlerScript | ✅ | ✅（需 link.xml） | ✅（UWR） | N/A |
| HttpClient | ⚠️ 需实机验证 | ⚠️ 需验证 | ❌ | ✅ |
| RawTcp/SslStream | ✅ | ✅ | ❌ | ✅ |
| SSE 增量 | ✅ | ✅ | ✅（fetch） | ✅ |
| WebSocket | ✅ 本地 ws + 远程 wss 实测通过（2021.3/6.3/6.6 × Mono/IL2CPP，2026-11-06/07）；关代理对照 pending | ✅ 同左 | ⚠️ M2（`.jslib`） | ✅ |
| 显式代理 | ❌（仅系统） | ❌ | 浏览器 | ✅ |
| 自签/企业证书 | ✅ certificateHandler | ✅ | 浏览器 | ✅ |
| HTTP/2 | ❌ | ❌ | 浏览器 | ✅ |
| 主线程回调 | ✅ 需 dispatch | ✅ | ✅ | N/A |
| 生命周期取消 | ✅ 需接入 | ✅ | ✅ | N/A |

> ✅ 支持；⚠️ 需实机验证/有条件；❌ 不支持。
> “支持”= 能编译 + 单测 + 目标平台实机冒烟；不是“理论上可用”。

## 4. 依赖与许可证策略

- **核心 Abstractions**：零 `UnityEngine`、零网络实现依赖；
- **SSE 解析器**：优先 vendor `System.Net.ServerSentEvents`（MIT）的 `netstandard2.0` 源码；避免依赖 .NET 9+ 包版本；
- **System.Memory / IAsyncEnumerable**：Unity 2021 自带/兼容性需编译验证；冲突时 vendor 或降级；
- **第三方库**：MIT/Apache-2.0；不引入原生插件/闭源 SDK；
- **mikito 示例**：无 LICENSE，**不可复制代码**；
- **LaunchDarkly.EventSource**：Apache-2.0，可选参考/桌面实现，不放进 Unity 核心；
- **com.openai.unity**：MIT，但 6 个 UPM 依赖，只参考不依赖。

## 5. 包与命名（建议）

```
UnityLlmTransport.Abstractions   // 纯接口/DTO，netstandard2.1
UnityLlmTransport.HttpClient     // HttpClient 实现（桌面/后端）
UnityLlmTransport.UnityWebRequest.Core   // 纯桥接/分类，netstandard2.1
UnityLlmTransport.UnityWebRequest        // Unity 适配资产（源码嵌入；link.xml）
UnityLlmTransport.RawTcp         // 可选兜底
UnityLlmTransport.Hosts.Unity    // 协程 Host/主线程/生命周期
```

- 仓库/显示名：`UnityLlmTransport`；
- NuGet/UPM 包 ID 建议加组织前缀（如 `YourOrg.UnityLlmTransport`），避免与官方混淆；
- 版本：`0.x` 阶段；接口稳定后再考虑 `1.0`。

## 6. 支持定义

一个平台/传输算“支持”，必须同时满足：

1. `netstandard2.1` 编译 0 错误；
2. 核心单测全绿（SSE、解码、超时、取消、错误分类）；
3. **2021.3.45f1、6000.3.28f1、6000.6.8f1 三个版本**各自 Mono 实机冒烟：真流式、取消、首字节/空闲超时、错误分类；
4. IL2CPP（如声明支持）在对应版本额外冒烟：handler 重写未被剥离；
5. 有 mock/录制回放回归。

否则只能标“实验/未验证”，不能写“支持”。

## 7. 待定决策

1. **Unity 版本**：已钉死 2021.3.45f1（主）、6000.3.28f1（6.3 LTS）、6000.6.8f1（6.6）；若目标游戏是 2021.2 需单独验证；
2. **WebGL**：M2 是否投入；
3. **HttpClient 传输**：M1 是否提供，还是只做 UWR；
4. **RawTcp**：是否保留兜底；
5. **WebSocket**：按 Codex 等 provider 需求再上；
6. **认证范围**：M1 只做 API Key 注入，OAuth/SigV4 后置；
7. **包管理**：UPM 包 vs NuGet vs 源码嵌入；
8. **命名**：`UnityLlmTransport` 的商标/官方混淆风险评估。
