## 2. 阶段 0 · Spike（事实确认）

**目标**：用最小实验回答“能不能做”，不写生产代码。

| 任务 | 内容 | 产出 |
|---|---|---|
| S0-1 | vendor `SseParser` 到 netstandard2.1：补 `ArrayBuffer.cs`、C# 11/12 语法降级、`IsExternalInit` | 编译报告 + 关键 parser 测试结果 |
| S0-2 | UWR `DownloadHandlerScript`：本地 SSE 服务，验证逐帧 `ReceiveData`、`gzip`、`Abort` 残留、`responseCode=0` | 事实报告 |
| S0-3 | 代理/TLS 矩阵：UWR vs HttpClient vs ClientWebSocket × 无代理/系统代理/显式代理 × 本地/远程 × 正常/自签 | 矩阵结果 + 错误分类 |
| S0-4 | WebSocket：`ws://127.0.0.1`、远程 `wss://`、IL2CPP 冒烟 | 支持等级结论 |
| S0-5 | IL2CPP：`DownloadHandlerScript` 重写、`link.xml`/`[Preserve]` | 构建/运行结论 |
| S0-6 | `ChannelReadStream`：UWR 回调 → 有界 Channel → `Stream` → SseParser | 桥接可行/死锁结论 |

**版本矩阵**：S0-2/S0-3/S0-4/S0-5 在 **2021.3.45f1、6000.3.28f1、6000.6.8f1** 各跑一次；结果按版本记录（同一资产，不放版本分支）。

**Go/No-Go**：

- UWR 真流式成立 → 进入阶段 2；
- UWR 逐帧/Abort 不成立 → 评估 HttpClient/RawTcp 作为主路径；
- `SseParser` 无法降级编译 → 自写最小 parser（保留 spec 测试）；
- 远程 wss 不成立 → WebSocket 仅本地/阶段 5 实验，M1 不承诺。

**门禁**：事实报告写入 `docs/`；不合并生产代码。

## 6. 阶段 4 · Auth / 签名（传输侧）

> 本阶段只做本仓库的认证/签名**钩子**，不包含、不依赖、不验收任何消费方集成。消费方（PiUnityAgent 等）自行通过其 Fetch 端口/适配器消费本组件；其 provider 联调与游戏内验收在消费方仓库执行。

| 任务 | 内容 |
|---|---|
| S4-1 | `ApiKeyMiddleware`：header 注入；key 由调用方/上层传入，本组件不存储凭据 |
| S4-2 | `OAuthTokenMiddleware`：只注入 token；刷新通过 `IAuthRefreshHandler` 钩子 |
| S4-3 | `IRequestSigner` + `SignerFinalizer`：在最终 header 上签名（SigV4/ADC/Azure AD 的算法由消费方实现）；仅 `RequestFinalizer` 能力的传输可用（UWR 不可用 → HttpClient） |
| S4-4 | 401 → refresh → 重试联调：结合 `RetryTransport` 验证最多一次 refresh，流开始后不重试 |
| S4-5 | Deferred/目录刷新/图片/分类的**传输形状**验证：通用 HTTP/流契约足够；provider 语义不在本组件 |

**门禁**：

- dotnet 集成测试：ApiKey/OAuth header 注入与 null 抑制、middleware 顺序；
- 401 refresh 最多一次；流开始后不重试；
- Signer 看到最终请求且传输层不再改写已签名 header；UWR 不被选用于签名路径；
- Deferred 长轮询/普通 HTTP 通过本组件传输（mock/本地服务）；
- **不包含任何消费方适配器/仓库门禁**；消费方验收另行执行。

## 9. 依赖关系

```
S0
 ├─ S1 ── S2 ── S5
 │        └─ S3 ── S4
 └────────────────── S6（贯穿）
```

- S0 必须先做；
- S1 可与 S0 部分并行（vendor parser 编译）；
- S2/S3 可并行（不同实现）；
- S4（Auth/签名）依赖 S3（签名路径要求 `RequestFinalizer` → HttpClient）；S2 可选联调；
- S5（WebSocket 核心）依赖 S1/S2；WS→SSE 回退与消费方协议层属消费方，不在本仓库；
- S6 贯穿，最后收口。
