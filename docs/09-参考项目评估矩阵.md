## 2. 关键订正（影响此前的直觉）

1. **mikito stream 分支不是 UWR**：实际是 `HttpClient + ResponseHeadersRead + StreamReader.ReadLineAsync`；UWR 版在 master/coroutine 分支。此前"mikito 证明 UWR 最小闭环"不成立。
2. **com.utilities.rest 的 SSE 不是 DownloadHandlerScript**：它逐帧重读 `downloadHandler.text` 全量串 + 字符索引增量解析，长流 O(n²)。只参考其请求/释放/证书封装。
3. **WorldTalk / 江湖有灵 / Yaolao 均为反编译或学习参考，未见开源 LICENSE**：只能参考模式，不能复制代码；文档与实现中要明确。
4. **NativeWebSocket 许可证冲突**：LICENSE 文本 Apache-2.0，csproj 写 MIT；按 Apache-2.0 处理，保留 NOTICE。
5. **ServerSentEvents vendor 不是零成本**：需补 `ArrayBuffer.cs`（sparse checkout 未含），C# 11 `u8` 字面量/C# 12 集合表达式需降级到 Unity 2021 的 C# 9。
6. **LaunchDarkly 的 `ResponseStartTimeout` 在注入自定义 HttpClient 时会被忽略**；`ReadTimeout` 是逐次读空闲超时；默认重连必须显式 `Close()` 关闭。
7. **江湖有灵的裸 TCP 是"可控的代价"**：分层超时/硬取消/解析分层值得学，但无代理/HTTP2/重定向/连接池，不应作为首选。
8. **Yaolao 的重试是整 POST 重发**：超时→ConnectionError→整段重试，可能重复计费；取消链路多处传 `CancellationToken.None`。

## 3. 架构输入（初步）

### 3.1 共识模式

- **传输只吐原始字节**；SSE/UTF-8 解析与协议聚合分离；
- **UWR + DownloadHandlerScript** 是 Unity 真流式主路径；默认 Buffer 不可用；
- **增量 UTF-8 decoder + 行缓冲**是正确姿势；
- **取消必须 Abort/关闭连接**；不是停止读取；
- **超时分层**：连接/首字节 + 流空闲；
- **UI 节流**；主线程只做轻量 dispatch；
- **错误体读取**与状态码/headers 一起分类。

### 3.2 分歧选择

| 分歧 | 选项 | 初步倾向 |
|---|---|---|
| UWR vs HttpClient | UWR 主路径 / HttpClient 可选 | UWR 必做；HttpClient 作为显式代理/自签/HTTP2 的第二实现 |
| 解析位置 | ReceiveData 主线程 / 后台 | 入队 + 后台解析；主线程只 dispatch |
| 原始 TCP | 首选 / 兜底 | 兜底；不默认 |
| SSE 解析器 | 自写 / vendor ServerSentEvents | vendor，降级语法后进核心 |
| 超时模型 | UWR timeout / 自管看门狗 | 自管：首字节 + 空闲 |
| WebSocket | 现在 / 阶段 5 | 阶段 5；NativeWebSocket 可 vendor |

### 3.3 空白（必须自建）

- 认证/签名钩子（API Key/OAuth/SigV4/ADC）；
- 分层超时公共件；
- Unity 主线程 dispatch / 生命周期；
- 跨传输统一接口（UWR/HttpClient/RawTcp/WS）；
- mock / 录制回放 / 错误注入；
- 错误分类词汇表（Connect/HttpStatus/Protocol/Parse/Idle/Cancelled）。

## 4. 对架构文档的输入

1. **核心层**：vendor `SseParser` + 自建 `Utf8ChunkDecoder`/`TimeoutPolicy`/`TransportError` + mock；
2. **UWR 传输**：自研 `DownloadHandlerScript`（参考 WorldTalk 的增量解码/行缓冲，但解析移出主线程）；
3. **HttpClient 传输**：参考 LaunchDarkly 的超时/错误语义，但禁用重连、补 CancellationToken；
4. **RawTcp**：只保留设计位置，不作为 M1 实现；
5. **WebSocket**：阶段 5，NativeWebSocket vendor；
6. **WebGL**：M2，fetch-event-source 的 parse.ts 作为移植蓝本；
7. **禁止**：依赖 com.openai.unity 全家桶、把 LaunchDarkly 整库放进 Unity 核心、复制无 LICENSE 代码。
